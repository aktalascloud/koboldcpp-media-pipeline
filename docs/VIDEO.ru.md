# Видео через медиасервер KoboldCpp

Используйте отдельный вызов видео, не параметры генерации изображений. Адрес сервера тот же, что у фото и музыки. Модель выбирает сервер: Wan2.2 TI2V5B Turbo Q4. После запроса сервер возвращает фото-модель в память GPU.

`GET /v1/videos/capabilities` — актуальные возможности.

`POST /v1/videos/generations`, JSON:

```json
{
  "prompt": "A cinematic shot of an adult woman in an elegant silver dress, natural blinking, subtle fabric movement, steady camera, warm hotel lobby lighting",
  "model": "kobold-wan22-turbo",
  "resolution": "480p",
  "orientation": "portrait",
  "frames": 17,
  "fps": 24,
  "seed": 424242,
  "upscale_to": "720p",
  "enhance_faces": true
}
```

Для оживления фото добавьте `image`: строка PNG base64, допускается префикс `data:image/png;base64,`. Для продолжения добавьте `continue_from`: ID предыдущего видео. Эти два способа взаимоисключающие. Продолжение использует исходный последний кадр до апскейла, чтобы не накапливать обработку лиц.

Ответ содержит `id`, `url`, `metadata`, а после улучшения также `native_video_url`. Покажите MP4 по `url`. Сервер поддерживает Range-запросы для проигрывателя. Не вставляйте локальные пути файлов в запросы.

Без `upscale_to` получается исходное видео 480p. Без `enhance_faces` лица дополнительно не обрабатываются. Оба улучшения можно включать независимо. Обычный фотопайплайн с Gater автоматически к видео не применяется.

Апскейл готового видео: `POST /v1/videos/upscale`:

```json
{"video_id":"ID_ПОЛУЧЕННОГО_ВИДЕО","enhance_faces":true}
```

Создаётся новый результат, исходный сохраняется. ClearReality FP32 DirectML увеличивает короткую сторону до 720 px. Для портрета это 720×1248, для пейзажа 1248×720: исходные пропорции сохраняются. Это не растягивание до 1280×720.

Проверенные параметры: 4 шага, Euler/simple, CFG1, shift5, eta0, без кэша. Не передавайте параметры фото, LoRA и музыкальные поля. Встроенный Turbo не требует дополнительной Turbo LoRA. По выбору пользователя по умолчанию включён Super-Tiny декодер; исходное фото кодирует полный Wan VAE. Проба на 49 кадров заняла около 140с только на Native. Скорость получена с видимой потерей деталей лица и глаз; это не улучшение без потерь.

Лица: YuNet960, GPEN20%, SFace≥0.97, максимум2 лица; GPEN работает через DirectML. Изменения лица сглаживаются между кадрами с компенсацией движения и повторной проверкой сходства. Это не гарантирует восстановление отсутствующих деталей глаз.

Лимиты: одно видео, число кадров 4n+1 от 5 до 121, 24FPS, общий бюджет запроса 900с. Проверены 17 и 49 кадров; верхняя граница 121 экспериментальная. Начните с 17 кадров, затем используйте 49 для ролика около 2,04с. Не растягивайте ролик изменением FPS и не выдавайте интерполяцию за новые сгенерированные кадры. Непрерывные 30с пока не проверены; цепочки продолжений могут менять лицо и композицию.

Составляйте короткий английский промпт: субъект, одно действие, движение камеры, окружение, свет. Для I2V описывайте преимущественно движение. Хелпер OWUI может быть любым, сервер не привязан к поставщику LLM.
