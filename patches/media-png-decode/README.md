# Decode matching PNG modes in place

Loads single-frame RGB/RGBA PNG data without copying pixels into an identical mode. Other formats, animated PNGs and color conversions use the existing path. Pixel bytes and metadata matched in ten controls.

Однокадровый PNG с готовым RGB/RGBA загружается без копии пикселей. Прежний путь обрабатывает другие форматы, анимацию и преобразования цвета.
