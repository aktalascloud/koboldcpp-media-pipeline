# Reuse the RGB provenance digest

Hash already-RGB images without converting them. Reuse the input digest for face and restoration markers before modifying pixels. PNG payloads and marker decisions matched in the controls.

Для уже готового RGB убрано копирование. Один SHA-256 используется для проверки обоих маркеров до изменения изображения. PNG и решения о маркерах совпали.
